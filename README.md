# KarmaDrift

KarmaDrift employs a distributed, event-driven architecture to enable scalable system-wide monitoring via a fault-tolerant node network.

KarmaDrift is aimed at developers who need a straightforward, dependable solution.

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/KarmaDrift.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure KarmaDrift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
